# КРИО/73 — сайт криочистки двигателя сухим льдом (Ульяновск)

Статический промо-сайт: HTML + CSS + JS без сборки и зависимостей. Все изображения и анимация
отрендерены в Blender из процедурной сцены (исходники в `blender/`).

## Структура

```
index.html              страница (7 разделов)
assets/css/style.css    стили, палитра и типографика
assets/js/main.js       интерактив + CONFIG с контактами студии
assets/img/             рендеры (WebP, hero ещё и JPG)
assets/seq/             60 кадров анимации очистки для скролла и превью
blender/                скрипты сцены и рендера
```

## Что заполнить перед запуском

Откройте `assets/js/main.js`, блок `CONFIG` в начале файла:

| Поле | Что это |
|---|---|
| `phone`, `phoneRaw` | телефон для показа и для ссылки `tel:` |
| `whatsapp` | номер WhatsApp без «+» (на него уходит заявка) |
| `telegram` | имя пользователя Telegram без @ |
| `vk` | ссылка на страницу ВКонтакте |
| `address`, `hours` | адрес студии в Ульяновске и режим работы |
| `formEndpoint` | необязательно: URL, принимающий POST JSON (Formspree, свой бот) |

Сейчас там заглушки (`+7 (900) 000-00-00`, «ул. Примерная, 1»). Цены (6 900 и 11 900 ₽)
и характеристики оборудования — тоже примерные, правятся прямо в `index.html`.

### Как работает заявка

Сайт статический, поэтому сервера для заявок нет. После отправки формы посетитель видит готовый
текст заявки и кнопки «WhatsApp» (откроет чат с вашим номером и подставит текст), «Telegram»
(скопирует текст и откроет ваш чат) и «Скопировать». Если указать `formEndpoint`, заявка
дополнительно уйдёт туда автоматически.

## Запуск локально

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000. Для хостинга подойдёт любой статический: GitHub Pages,
Netlify, Яндекс Object Storage, обычный виртуальный хостинг (загрузить папку целиком).

## Пересборка изображений в Blender

Нужен Blender 4.2+ (или `pip install bpy`). Всё процедурное, внешних моделей нет.

```bash
cd blender
./queue.sh                     # hero, до/после, зоны, 60 кадров анимации (~1,5 ч на CPU)
python3 equipment.py gun       # gun | nozzles | pellets
python3 export_assets.py       # PNG → WebP/JPG в assets/
```

`engine_scene.py` собирает моторный отсек V8. Грязь — общий слой во всех материалах,
её маской управляет значение `DirtControl → Threshold`: левее порога по оси X мотор уже чистый,
правее — ещё грязный. Анимация двигает порог вместе с соплом.
Чтобы открыть сцену в интерфейсе Blender: `python3 render.py save` создаст `engine_bay.blend`.
