# КРИО/73 — сайт криочистки двигателя сухим льдом (Ульяновск)

Статический промо-сайт: HTML + CSS + JS без сборки и зависимостей.

## Структура

```
index.html               страница (7 разделов + фото-вставка процесса)
assets/css/style.css     стили, палитра и типографика
assets/js/main.js        интерактив + CONFIG с контактами студии
assets/img/              фото (WebP, hero ещё и JPG для превью в соцсетях)
tools/dirty.py           делает кадр «до» из чистого фото «после»
tools/export_photos.py   PNG → WebP + генерация «до»
```

## Фото

Все изображения сгенерированы ИИ (через Figma AI) и являются **иллюстрациями**, а не
снимками реальных работ. Как только появятся фото ваших машин, замените файлы
в `assets/img/` с теми же именами:

| Файл | Где на сайте |
|---|---|
| `hero` | первый экран |
| `after`, `before` | слайдер «до/после» и анимация очистки (кадры должны совпадать по ракурсу) |
| `zone_block`, `zone_wiring`, `zone_turbo`, `zone_hoses` | «Зоны под капотом» |
| `gun`, `nozzles`, `pellets` | «Оборудование» |
| `case_sport`, `case_premium`, `case_classic`, `case_daily` | «Типы авто» |
| `process` | фото-вставка перед тарифами |

Для «до/после» лучше снять мотор с штатива с одной точки до и после чистки.
Если есть только чистый кадр, `tools/dirty.py` сделает из него грязный вариант:

```bash
python3 tools/export_photos.py   # берёт assets/photo_raw/*.png
```

## Анимация

- Раздел «Технология»: при прокрутке фронт очистки с полосой инея идёт по фото слева направо,
  снимает грязь (`before` → `after`), из точки удара струи идёт пар. HUD показывает процент очистки,
  карточки физики процесса переключаются по ходу.
- Карточка «Процесс очистки» на первом экране показывает ту же анимацию в цикле.
- Туман на первом экране, 3D-наклон карточек оборудования, параллакс фото-вставки, появление блоков.
- При `prefers-reduced-motion` анимации отключаются или упрощаются.

## Что заполнить перед запуском

Откройте `assets/js/main.js`, блок `CONFIG` в начале файла:

| Поле | Что это |
|---|---|
| `phone`, `phoneRaw` | телефон для показа и для ссылки `tel:` |
| `whatsapp` | номер WhatsApp без «+» (на него уходит заявка) |
| `telegram` | имя пользователя Telegram без @ |
| `vk` | ссылка на страницу ВКонтакте |
| `address`, `hours` | адрес студии в Ульяновске и режим работы |
| `formEndpoint` | необязательно: URL, принимающий POST JSON (Formspree, свой бот) |

Сейчас там заглушки (`+7 (900) 000-00-00`, «ул. Примерная, 1»). Цены (6 900 и 11 900 ₽)
и характеристики оборудования примерные, правятся прямо в `index.html`.

### Как работает заявка

Сайт статический, сервера для заявок нет. После отправки формы посетитель видит готовый
текст заявки и кнопки «WhatsApp» (откроет чат с вашим номером и подставит текст), «Telegram»
(скопирует текст и откроет ваш чат) и «Скопировать». Если указать `formEndpoint`, заявка
дополнительно уйдёт туда автоматически.

## Запуск локально

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000. Для хостинга подойдёт любой статический: GitHub Pages,
Netlify, Яндекс Object Storage, обычный виртуальный хостинг (загрузить папку целиком).
